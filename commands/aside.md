# Command: aside

Capture a mid-session thought — or several raised in one breath — as a triage-ready
`docs/inbox/` item, without derailing the current task. The write side of the inbox;
`check-inbox` is the read/triage side.

## When to run
- Manually, whenever the developer raises something worth remembering but out of scope
  for right now
- Mid-session, without switching focus — write the item and return control immediately

## Dispatches to
`workflows/aside.md`
