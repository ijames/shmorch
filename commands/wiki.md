# Command: wiki

Audit the learning log (global `~/.shmorch/learning/` + project `docs/reference/learning/`):
promote concepts that have recurred across projects, and report how far the current
frontmatter/index/log conventions diverge from the llm-wiki reference pattern.

## When to run
- Manually, periodically — same rhythm as `self-improve`
- Whenever a concept capture feels like it's duplicating something already learned elsewhere

## Dispatches to
`workflows/wiki.md`
