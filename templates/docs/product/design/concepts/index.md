# Design Concepts

↑ [design/](../index.md)

Persistent design thinking — the product's mental models, philosophy, and framing that
outlive any one track. Built by design tracks; read by implementation tracks. Not a spec
and not a decision — when a concept firms up into something decided, move it to
[decisions/](../../decisions/index.md).

Keep each concept in its own file (~200–400 lines max, per the graph-first-docs
discipline) and list it below.
