# Development Concepts

↑ [development/](../index.md)

Landing place for captured thinking that isn't a decision yet — concepts, design
philosophy, feature ideas with enough depth to be worth keeping in full. Persistent,
living thinking — built by dev tracks, consumed by implementation tracks. Nothing here is
a spec or a plan. When something graduates to a decision, move it to
[technology/decisions/](../../decisions/index.md).

Keep each concept in its own file (~200–400 lines max, per the graph-first-docs
discipline) and list it below.
