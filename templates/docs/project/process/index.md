# Process

↑ [project/](../index.md)

Divergences from Shmorch's own paved-road defaults (`core/operations.md`,
`core/git-discipline.md`, etc.). Each divergence gets a documented decision plus the
override that supersedes the default — e.g. a non-default PR merge strategy, a different
branch naming scheme. These are concrete overrides, not soft preferences — they belong
here, not in `product/decisions/` or `technology/decisions/`.
