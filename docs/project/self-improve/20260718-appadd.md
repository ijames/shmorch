#### Proposal 1: Sessions routinely end without `/shmorch wrap` running
**Pattern:** `session.md` contains 14 instances of `SESSION_END | auto-wrapped on reentry` (timelog) paired with session.md entries explicitly marked `_(reconstructed from git log — session ended without wrap)_` — e.g. 2026-07-08, 2026-07-06, 2026-07-05, 2026-07-02, 2026-06-29 (partial), 2026-06-28, 2026-06-20/21, 2026-06-15, 2026-06-14 (x2), 2026-06-13/14, 2026-06-19. This is the single most frequent friction in the whole log — more than 40% of logged sessions since late April show this pattern.
**Frequency:** 14 occurrences across ~11 weeks.
**File:** `workflows/wrap.md` (skill default) — add an explicit trigger, not just a manual command.
**Change:** Add a `go`-time check: if the previous `SESSION_END` in `timelog.md` is `auto-wrapped on reentry` (i.e., the prior session never ran a real wrap), `go` should reconstruct-and-append the missing session.md entry from git log *before* orienting further, rather than leaving it to accumulate. **Improvement:** Removes the recurring "reconstruct from git log" tax paid at the start of nearly every other session, and stops session.md drift from compounding (note 2026-06-29 session.md was "one session behind at start of day").
