```bash

  .githooks/ .git/hooks/ .github/ scripts/ .claude/hooks/ 2>/dev/null
```
(generalized: grep tooling directories for any doc path segment that no longer exists in the current tree) and flag any hit as a stale-reference bug to fix immediately, not defer.
