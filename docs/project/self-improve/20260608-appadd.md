**Pattern:** Intent discussions end with "deferred — pending X decision" captured only in `session.md` next-up notes. No track stub is created. Next session has to reconstruct the deferred decision from prose rather than finding a structured stub.

**Frequency:** Seen this session (header/nav deferred, no track opened), and in earlier sessions where design decisions sat in session notes for 2–3 sessions before a track was opened.

**File:** `~/.claude/skills/shmorch/shmorch-core.md` — "95% confidence" / intent section

**Change:** Add rule: "If intent is deferred — decision pending, more review needed, or blocked — open a stub track immediately with `Status: Blocked — pending [decision]` and the open question documented. Never park a deferred intent only in `session.md`."

**Improvement:** Deferred decisions have a structured home. Next-session go workflow surfaces them via track scan rather than requiring session.md reading.

#### Proposal 2: Wrap Step 6.5 graduation should check destination docs, not just track status

**Pattern:** Tracks marked `Status: Complete` accumulate over sessions without their knowledge landing in destination docs. This session's documentarian run closed 5 gaps (filter-sort, ingest-in-grid, responsive-layout sections missing from `frontend-interaction.md`) that had been open for 3+ sessions. The wrap Step 6.5 check only asks about `Status: Closed` — it silently passes `Status: Complete` tracks whose destination docs are empty.

**Frequency:** 5 destination gaps caught in this session's documentarian run; all from tracks closed 3–5 sessions ago.

**File:** `~/.claude/skills/shmorch/workflows/wrap.md` — Step 6.5

**Change:** Extend the grep to also catch `Status: Complete` (not just `Status: Closed\|Status: Done`). For each hit, read the `→ destination` line and check whether the destination file was modified after the track's `Opened:` date: `git log --since="<opened-date>" -- <destination-file>`. If no commits found on that file since the track opened, flag it as "knowledge not yet graduated."

**Improvement:** Graduation gaps are caught at wrap time rather than accumulating until a manual documentarian run.
